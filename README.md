# React + TypeScript + Vite

### Component library and styling

`Tailwind` and `shadcn/ui` for component library and styling

### Data fetching with TanStack Query

`useQuery` is used to simulate a real API call

### Context for state management

A `TaxCalculatorContext` To avoid prop drilling

### Zod schema validation

For API schema validation and form validation

## Getting Started

```bash
npm install
npm run dev
```

## Running Tests

```bash
npm run test
```
